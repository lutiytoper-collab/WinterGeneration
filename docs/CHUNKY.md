# Предварительная генерация

Chunky **1.4.40** реально проверен с Paper 1.21.11 build 132, WorldEdit и FAWE в отдельных профилях. Ограниченные задачи завершились. Итоговые console logs и объём — reports/COMPATIBILITY_REPORT.md. Это не доказательство достаточности для 100 игроков.

После smoke-теста и бэкапа нового мира:

```text
chunky world winter_test
chunky shape square
chunky center 0 0
chunky radius 256
chunky start
chunky progress
chunky pause
chunky continue
```

Начните с небольшого радиуса. Сохраняйте консоль и измеряйте vanilla baseline на том же seed и ресурсах. Плагин обрабатывает ChunkPopulateEvent новых чанков; существующие чанки не получают повторный декор. Если соседние сведения о структурах не успели стать доступны, ограниченная очередь пропускает чанк по TTL; консервативная защита может уменьшать плотность объектов. Не используйте `/reload` для смены worldgen datapack.

В QA задача задавалась в центре 4096,4096 радиусом 64 блока; Chunky сообщил 81 чанк. Повторные задачи в уже созданной области подтверждают отсутствие повторной обработки, но не являются измерением новой генерации 81 чанка. Различайте generated/requested/visited в логах и замерах.
