# Лунные арки, святилища и руины

В 0.5.0 добавлены шесть небольших композиций: две лунные арки, каменное и лесное святилища, каменные и деревянные руины. В композиций входят короткие подходы и небольшие боковые камни/кусты. Деревянные варианты выбираются для лесов, каменные — для холодных биомов; на равнинах доступны все варианты. Это локальные композиции, сеть дорог между удалёнными зданиями не создаётся.

Из интернета взята **геометрия кругов**, а не готовые дома: [Greaby/minecraft-circles-schematics](https://github.com/Greaby/minecraft-circles-schematics), CC0-1.0, commit `1263463cffb59b08275e9ee9408848285c4cddff`. Оригиналы/хеши сохранены в vendor/schematics/greaby-circles/, лицензия — также в JAR. Четыре святилища/руины созданы для этого проекта.

scripts/schematics.py проверяет исходные хеши, предел распаковки, единственный плоский регион, палитру air/stone и отсутствие entities, block entities и ticks. Контуры разворачиваются вертикально. Палитра — диорит, обычный камень, древесина, цветное стекло и снег; источники света — дешёвые светильники Джека. Драгоценных блоков, аметиста, редких ламп, уплотнённого/синего льда, контейнеров и лута нет. Исходный воздух не вставляется.

Для каждого шаблона есть JSON-план плагина и vanilla NBT внутри data/midgard/structure/ встроенного датапака. NBT — доступные ресурсы, а естественное размещение выполняет плагин. Native worldgen structure definitions не добавлены. WorldEdit для шаблонов не требуется.

Настройки: modules.schematics: true, schematics.chance: 0.0125. Шаг сетки — 8 чанков; шанс внутри ячейки равен min(1,chance×64). При значении 0.0125 это 80% подходящих центров, максимум один кандидат на 64 чанка до проверок. Фактическая частота ниже из-за уклонов/препятствий. При 0 размещение отключено; при 1 центры всё равно разделены сеткой.

Все четыре поворота проходят общий preflight: один чанк, размер ≤11×11, лимит 512 записей, проверка биома/опор/занятости/WG/структур/игроков/Luna. На перепаде до двух блоков опоры продлеваются без срезания земли. Неподходящее место пропускается целиком. Шаблоны используют блоки без направленных лестниц/дверей.

Это каталог встроенных проверенных шаблонов, не универсальный импорт .schem/.litematic. Большие многокусковые здания, ориентированные двери/лестницы и мосты через настоящие реки пока не реализованы: для мостов требуется отдельная проверка обоих берегов. Файлы с неизвестными блоками не проходят белый список.

Все композиции обычные разрушаемые блоки. Плагин не создаёт приватов и не запрещает игрокам строить/ломать/взрывать декор. Проверки защиты предотвращают перезапись мира генератором. Правила установленных отдельно WorldGuard/Luna и других плагинов регулируются их настройками.
