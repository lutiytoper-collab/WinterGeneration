# Fantasy 0.4.0: установка одного JAR

Платформа строго **Paper/Purpur 1.21.11, Java 21**.

1. Остановите тестовый сервер и сохраните его состояние. Уберите старую копию MidgardWinterWorld из plugins/, оставьте один новый MidgardWinterWorld.jar либо MidgardWinterWorld-0.4.0.jar.
2. Запустите сервер. Встроенный pack подключится до первой генерации мира через Paper DATAPACK_DISCOVERY. В логах появится FANTASY_PACK_DISCOVERED MidgardWinterWorld/fantasy, а /datapack list enabled покажет этот pack. /winterworld status покажет версию 0.4.0.
3. При первой установке конфиг создаётся автоматически. Поздний декор разрешён в world и winter_test; для другого имени добавьте его в allowed-worlds. Новый параметр modules.wonders управляет ивами/грибами/лунными камнями, modules.ice — большими кристаллами. Native forest и палитру включает fantasy-pack-enabled; это bootstrap-настройка, для её изменения нужен полный перезапуск, а не reload.
4. Для цельного сравнения используйте новый мир/новые чанки. Для показанного ландшафта seed825180311, первый кадр 30,72,190, цветущая роща около 512,768. Старые PDC processed_v1 маркеры сохраняются; ретрогенерации нет.

Если раньше ставили Storybook 0.3, не смешивайте старые внешние storybook-datapack.zip/winter-datapack.zip со встроенным паком в новой тестовой установке. Файлы старого config.yml не перезаписываются автоматически. modules.wonders по умолчанию true при отсутствии; явное false сохраняется. Старое значение modules.forests может включать дополнительные overlay-деревья, новый профиль использует false.

Native biome registry глобален для сервера: цвета/климат влияют и на уже существующие биомы; plugin allowed-worlds ограничивает поздний декор, не registry. Все сочетания внешних конкурирующих паков, изменения pack через hot reload и все края крон не проверены.

Готовый Midgard-Fantasy-0.4.0.zip содержит plugins/MidgardWinterWorld.jar и эту инструкцию. Серверный JAR, eula.txt и пользовательские WG/Luna зависимости не включены. Согласие EULA для облачного QA уже дано; установка своего сервера выполняется администратором.

Нагрузка 50–100 игроков не измерена. Для основной площадки сначала выполните осмотр и ограниченную предварительную генерацию. Постоянная листва/добываемые фонари и новые декоративные материалы меняют ресурсы выживания; экономика не проверена. Пробный runtime WinterProbe не нужен для игры.
