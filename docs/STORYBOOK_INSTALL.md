# Установка Storybook 0.3.0

Нужен новый отдельный сервер **Paper/Purpur 1.21.11, Java 21**. Готовый Midgard-Storybook-0.3.0.zip содержит такую раскладку:

```text
plugins/MidgardWinterWorld.jar
plugins/MidgardWinterWorld/config.yml
winter_test/datapacks/storybook-datapack.zip
INSTALL-RU.md
SHA256SUMS
```

1. Остановите тестовый сервер и распакуйте комплект в его корень. Если это существующая тестовая установка, сначала сохраните её целиком; старые миры комплект не перерисовывает.
2. В server.properties задайте level-name=winter_test. Для ландшафта с кадров используйте level-seed=825180311. До первого создания мира winter_test/datapacks/storybook-datapack.zip уже должен находиться на месте.
3. Убедитесь, что установлен именно Storybook config.yml из комплекта. Обычный dist/config.yml относится к более сдержанному overlay-режиму. Для другого имени мира исправьте allowed-worlds, имя каталога и level-name согласованно.
4. Не подключайте одновременно winter-datapack.zip: Storybook уже включает его зимний климат, а порядок конкурирующих biome overrides влияет на итоговый вид.
5. Запустите сервер, проверьте /datapack list enabled (storybook-datapack.zip), /winterworld status и новую область. На совпадающем seed кадр леса снят с 10,112,86, yaw−36.87/pitch24, без шейдеров. Плагин не содержит команды телепорта; штатный tp требует прав оператора.
6. После осмотра сохраните/перезапустите сервер. При необходимости подключайте WorldGuard и один WorldEdit/FAWE, затем Luna по отдельной инструкции. WinterProbe.jar для игры не устанавливайте.

Вы уже приняли Minecraft EULA для облачного тестового сервера; это не меняет порядок настройки вашего собственного сервера. Серверный JAR и eula.txt в комплект не включены.

Плагин не перезаписывает существующие обработанные чанки. Native-деревья появляются в новых чанках. Цвета/климат biome registry глобальны для сервера и могут менять вид старых биомов без изменения блоков; datapack не ограничивается allowed-worlds плагина. Для цельного результата используйте новый мир на отдельной площадке.

Сначала выполните контролируемую предварительную генерацию. Прогон 50–100 игроков не выполнен. Большие native-кроны, постоянная листва и добываемые фонари — намеренные особенности режима; баланс, все пограничные кроны и полный Purpur plugin stack не проверены. Полный список ограничений находится в reports/KNOWN_ISSUES.md исходного проекта.
