# Ограничения 0.5.0

1. TEST VERIFIED в указанном объёме, не RELEASE CANDIDATE. Каталог сохраняет 301 PASS /1 FAIL /11 NOT RUN; старые и промежуточные прогоны не засчитаны как новые.
2. Исходный height-window fingerprint 825180311/131,135 FAIL из-за разных выбранных координат. Независимая сверка одинаковых координат прошла; область сравнения ограничена пересечением окон, не всеми подземными блоками всего мира.
3. Климат/цвета biome registry глобальны для сервера. allowed-worlds ограничивает поздний декор. Native кроны могут пересекать чанки и биомы; все края и высоты не проверены.
4. Лимит 512 записей/11×11 относится к поздним объектам. Бюджет 2 ms мягкий: первый начатый объект может его превысить. Проверки WG могут быть дорогими при большом числе регионов.
5. Полный 50–100 player soak, стабильные 20 TPS, peak RSS и боевой plugin stack не проверены. Клиентский FPS llvmpipe не является server TPS.
6. Нет драгоценных материалов и редких ламп в новом декоре; дерево/снег/стекло/тыквы добываются. Экономика конкретного сервера не измерена. Старые ценные блоки не удаляются автоматически.
7. Генератор не создаёт приваты и не запрещает игрокам ломать/строить/взрывать. Правила WorldGuard/Luna и других плагинов отдельно не переопределяются. Проверки защиты ограничивают работу генератора.
8. Две арки используют CC0-контуры кругов, четыре композиции собственные. Универсальный импорт .schem, многокусковые здания, направленные двери/лестницы, мосты и сеть дорог не реализованы. NBT — встроенные ресурсы; естественно размещает плагин.
9. Текущий Purpur проверяет enabled→disabled restart и 4 ROI. Полный WG/Luna/WE/FAWE стек проверен на Paper. Нужны точные Paper/Purpur 1.21.11 и Java 21.
10. Luna QA: radius 1 (3×3), max-y 128, snow-only blacklist; поставка radius 2 (5×5). Active restart, hot reload/dynamic creation, custom Y кроме 1 и чужие поздние location changes не проверены. Поиск ограничен, подходящее место может находиться несколько минут.
11. Cloud refreshYggdrasil/Realms даёт сетевые ошибки; публичный Microsoft login не проверен. QA-клиенты работают через loopback offline-auth. TLS/CA/хеши не отключались. Сообщение missing flat layers относится к отдельному synthetic fixture world, не к поставляемому датапаку.
12. Галерея выборочно подтверждает арки и святилище, не все биомы/объекты. Неудачные кадры и прерванные cloud/client попытки сохранены отдельно. Нет автоматического ретрогена/отката; WinterProbe.jar только для QA.
