# Аудит 0.5.0

Подтверждённые исправления:

| Проблема | Исправление | Проверка |
|---|---|---|
| Async callbacks обходили лимит фактической работы за тик | TickWorkBudget считает выполненные callbacks, откладывает следующие | 6 unit-тестов, runtime budget-deferred |
| enabled:false оставлял native pack включённым | BootstrapSettings проверяет оба выключателя до discovery | 5 unit-тестов и enabled→disabled restart Purpur |
| Втягивание липкого поршня не инвалидировало queued декор | Инвалидация исходных/соседних destination чанков | Public Bukkit event fixture через границу чанка, не физическая redstone-модель |
| Оборванный pending marker оставался равным 1 | Уже загруженный orphan помечается skipped, без retrogen/загрузки соседей | Fixtures orphan/live pending, restart |

Дополнительно по запросу анархии удалены ценные материалы из всех новых blueprint и native tree decorators. Белый список блоков запрещает вернуть их через встроенный JSON. Добавлены две адаптации CC0-контуров и четыре собственные композиции. Метки чанков предотвращают повторную добычу через автоматический retrogen.

Оставшиеся ограничения: мягкий бюджет допускает превышение на одном начатом объекте; native registry глобален; кроны могут пересекать чанки/биомы; полного 50–100 player soak нет. Проверки WG перебирают регионы и могут стать дорогими на серверах с очень большим их числом. Большие здания/мосты и сеть путей не входят в текущую реализацию.

Приоритет дальнейшего развития: проверяемые мосты по двум берегам, дополнительные лицензированные силуэты зданий, региональные композиции со связанными путями, замер под реальным plugin stack. Без бенчмарка не заявляется стабильные 20 TPS или отсутствие любых багов.
