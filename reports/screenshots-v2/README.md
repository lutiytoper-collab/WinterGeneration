# Настоящие игровые кадры MidgardWinterWorld 0.2.0

6 ноября 2026. Официальный немодифицированный Minecraft **1.21.11**, Paper 132, Java 21, FAIRYTALE. Новый winter_test, seed 825180311, зимний датапак установлен до генерации. Шейдеров, resource pack, генерации изображений и обработки PNG нет. Все пять файлов сохранены самой игрой через F2 и скопированы без изменения байтов.

| Кадр | Содержание |
|---|---|
| [01-snow-conifers.png](01-snow-conifers.png) | Крупная процедурная ель у 25,78,106, объёмные снежные ветви и исходный хвойный лес |
| [02-lantern-clearing.png](02-lantern-clearing.png) | Автоматически размещённая арка с фонарём, скамья и камни на горной поляне |
| [03-mixed-forest.png](03-mixed-forest.png) | Смешанный заснеженный лес с дополнительными лиственными кронами |
| [04-forest-lantern.png](04-forest-lantern.png) | Такая же небольшая поляна среди естественных деревьев, в сумерках |
| [05-f3-proof.png](05-f3-proof.png) | Экран F3: vanilla1.21.11, Java 21, Paper, координаты и Mesa llvmpipe |

Разрешение 1600×900, render distance10, gamma0.6, программный OpenGL 4.5. Камера spectator; ясная погода и время выставлялись командами. Блоки для кадров вручную не ставились. Только локальный offline-auth QA на 127.0.0.1; публичная Microsoft-аутентификация здесь не проверялась.

В [provenance.json](provenance.json) указаны версия, SHA-256 текущего JAR/датапака/каждого PNG, официальный clientSHA-1, исходные F2-имена, UTC-время и координаты камеры. Оригиналы сохранены в приватной runtime-папке, а публичные PNG побайтно им соответствуют. Логи: ../logs/fairy02-final-client-console.log и ../logs/fairy02-final-world-console.log. Скрипт воспроизведения съёмки — scripts/capture-visual.py.

Сначала Chunky обошёл 1089 чанков, затем клиент загрузил дополнительные чанки вокруг выбранных мест. Снимок счётчиков в ../fairy02-visual-metrics.json относится к этапу 03:38UTC:306 елей,121 лиственное дерево,11 полян,3233 блока троп,76355 снега на кронах и 131262 наземных снежных позиций. Это счётчики удачных размещений, а не число уникальных деревьев на всём сервере или охват только 1089 Chunky-чанков. Позднейшие счётчики в console.log выше из-за загрузки новых областей клиентом.

Это выбранные реальные виды. Они подтверждают внешний вид проверенных мест; полная художественная приёмка всех биомов, переходов и модулей остаётся отдельной задачей. Первые кадры 0.1.0 сохранены в ../screenshots/ для сравнения.
