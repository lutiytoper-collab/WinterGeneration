# Ограничения Fantasy 0.4

1. Native pack включён в JAR и подключается при bootstrap. Изменение fantasy-pack-enabled требует полного restart. Старые внешние climate/Storybook ZIP и все их приоритетные сочетания не проверены; для новой установки оставьте встроенный вариант. Native registry глобален для сервера, allowed-worlds ограничивает поздний декор, не biome colours/climate.
2. Старые чанки не перерисовываются. Новый мир/новая область нужны для новых деревьев/объектов. Цвета/климат registry могут менять отображение старых биомов. Старый config.yml сохраняется, включая allowed-worlds; default новой установки world/winter_test. modules.wonders отсутствующий считается true, явное false учитывается.
3.1 diagnostic FAIL сохранён: height-window fingerprint825180311/131,135 выбирает разные координаты из-за высоты новых стволов. Same-coordinate1 572 785states и все сравниваемые *_ore позиции/состояния совпали. Это ограниченная одна seed/64 пары выборка, не весь мир.0.3 два seed/7,9 млн остаются историей.
4. Нагрузка 50–100 игроков/soak/TPS/peakRSS не проверена. Native кроны могут содержать тысячи блоков;512 лимитирует только поздний проход.2ms budget мягкий между чанками. Реальные выбросы и request latency приведены в PERFORMANCE_REPORT.md. Прегенерация порциями предпочтительна.
5. Все края native-крон и высокогорные климатические границы не проверены. Origin allowlist не гарантирует отсутствие каждой ветви вне биома. Native engine trees не являются WG-декоратором; поздние объекты сохраняют WG/структуры/players/block entities/Luna preflight. Crash atomic rollback отсутствует.
6. Листва persistent; после рубки ствола крона может остаться. Foliage loot соответствует использованным oak/cherry block types. Светящиеся грибы/камни/фонари содержат добываемые декоративные ресурсы. Экономика, плагины рубки деревьев и все сочетания добычи не проверены.
7. Визуально подтверждены все новые типы и отдельный flower_forest, есть 5 native F2. Полная художественная приёмка всех 23 биомов/переходов не выполнена. Домики выключены. Тропы не гарантируют связную дорожную сеть. В ледяных кристаллах обычный ICE заменён на не тающий packed/blue ice; полная длительная физическая симуляция всех декораций не выполнена.
8. Purpur прошёл one-JAR initial/restart4ROI; весь WG/Luna/WE/FAWE стек проверен на Paper. Native public API экспериментален в Paper, поддерживается только точная версия 1.21.11.
9. Luna QA radius1(3×3),max-y128,snow-only blacklist; поставка radius2(5×5). Активный restart,hot reload/dynamic creation,большие схематики,customY кроме 1,чужие поздние location changes не проверены. Поиск bounded, отсутствие места может задержать дроп.
10. Внешний refreshYggdrasil keys даёт сетевые ошибки в облачных логах; public Microsoft login не проверен. Graphical/protocol QA —127.0.0.1offline-auth. TLS/CA/хеши не отключались.
11. Runtime DEVELOPMENT/UNVERIFIED строки консервативны, фактическая QA описана отдельно. WinterProbe.jar только для QA. Автоматического отката/ретрогенерации нет. Исторические отчёты и неудачные промежуточные прогоны не объявляются текущими PASS.
