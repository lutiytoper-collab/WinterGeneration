# MidgardWinterWorld0.4.0 — Fantasy в одном JAR

Готовый MidgardWinterWorld-0.4.0.jar включает native-генерацию и поздний декор. Paper bootstrap регистрирует pack через публичный DATAPACK_DISCOVERY до создания мира; отдельный внешний датапак для обычной установки не нужен. Команда winterworld переведена на публичный Paper command lifecycle. Optional WG/Luna/FAWE мосты сохранены и проверены.

**TEST VERIFIED в указанном объёме:255 PASS /1 FAIL /0 BLOCKED /11 NOT RUN. Не RELEASE CANDIDATE.**161 Java и 16 Python PASS без skipped, опубликованный Paper API1.21.11, Java 21, Luna contract с настоящим предоставленным JAR.

## Внешний вид

Новая native winter_blossom форма и розовый цветущий forest; разные холодные/лавандовые/мятные/аметистовые биомные палитры. В позднем проходе — розовые ивы с обычными/душевными фонарями, светящиеся бирюзовые грибы, лунные камни и голубые кристаллы с аметистовыми вершинами. Всё — обычные блоки, без новых entities или фоновых particle loops.

После первого 625-chunk Chunky прохода, до входа клиента, зарегистрированы 59 грибов,39 ив,39 лунных камней,4 кристальные композиции и 5 полян. Это счётчики поздних объектов этого этапа, не число native деревьев и не финальный охват всех подгруженных позже чанков. Поздний snapshot — fantasy04-visual-metrics.json.

[Пять настоящих F2 PNG](screenshots-fantasy04/README.md): все новые виды и цветущая роща, плюс F3. Официальный vanilla1.21.11, без shaders/resource pack, обработки и ручного строительства сцены. PNG проверены CRC/IEND/SHA и побайтным совпадением с оригиналами.

## Исправления размещения

Кристаллы получили отдельную offset-сетку: поляны больше не занимают все кандидаты. Если один вид не разместился, проверяется следующий. Якоря учитывают фактические размеры шаблона; минеральные основания следуют перепаду до 2 блоков без изменения почвы. В светящихся кристаллах нет тающего обычного ICE. Все поздние объекты проходят тот же fail-closed preflight по biome/WG/структурам/опорам/бюджету/игрокам/Luna.

Для установки замените старый JAR одним новым, перезапустите сервер и смотрите новую область/новый мир. Старые внешние pack ZIP в новой установке не нужны; конкурирующие комбинации не тестировались. Облачная конфигурация не публиковалась и старые draft-изменения не применялись повторно.
