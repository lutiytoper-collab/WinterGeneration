# Ограничения 0.2.0

TEST VERIFIED относится к перечисленным реальным сценариям, а не к готовности сервера со 100 игроками. Точные статусы — test-results.json.

1. **Нужны новые чанки и новый config.yml.** Старые processed_v1 маркеры намеренно сохраняются; ретрогенерации/уборки декора нет. Старый max-object-size7 отклонит крупные формы. Allowlist плагина не меняет 23 климатических определения датапака.
2. **Производительность:** насыщенный FAIRYTALE дороже. В графическом прогоне median1.48ms, p9514.16ms и max 846.62ms на callback. Лимит 2ms мягкий и не прерывает начатую атомарную проверку/запись чанка. Полный длительный 50–100 игроков soak/TPS/peakRSS не выполнен; предварительная генерация предпочтительна.
3. **Строгий restart FAIL:** seed 42 меняет 6 raw underground state hashes initial/restart;1 геометрический fingerprint, deltaGLOW_LICHEN−1/AIR+1. Причинность state updates не установлена. После одинакового restart320/320 пар на двух seed совпадают с vanilla по всем сравниваемым underground raw states/структурам/block entities. Поверхность/PDC стабильны. Проверенный подземный срез ограничен −64..min(31, surface−8), не всеми блоками.
4. **Purpur:** текущий smoke4ROI прошёл. Отдельная матрица остановилась на surfaceByBiome vanilla-контроля; полная Purpur матрица и plugin stack остаются непроверенными.
5. Настоящие F2-кадры уже есть, выбранные места визуально осмотрены. Исчерпывающая художественная приёмка всех 23 биомов/переходов/модулей не выполнена. Домики выключены до отдельной проверки; новая тропа зависит от пологого рельефа, защиты и доступного бюджета, не гарантирует непрерывную дорожную сеть.
6. Консервативные WG/block entities/поверхностные структуры/игроки и препятствия сокращают плотность. Дополнительные деревья сохраняют native стволы; итог не обязан совпадать при другом порядке загрузки, встрече игрока или истечении очереди. Структуры без доступной API metadata/block entities не гарантированно распознаются. Авария между записями может оставить частичный объект, rollback не реализован.
7. Полная высотная граница всех биомов не проверена. Boundary guard в неоднозначных высокогорных условиях действует консервативно. Датапак рекомендуется использовать вместе с плагином; глобальное отсутствие native утечки снега вне allowlist не доказано.
8. Luna QA использует 3×3 radius 1 вместо default 5×5 radius 2, max-y128 и snow-only blacklist. Крупные схематики, Y offset кроме 1, активные дропы через restart, hot reload/dynamic creation и чужие поздние изменения location остаются NOT RUN. Поиск 32 района/5 мин,16 позиций/район; после End30s cooldown. Отсутствие площадки может задержать дроп.
9. Проверка полости ограничена support-depth. Глобальный WG-регион запрещает декор всего мира; ошибка WG API закрывает размещение. Проверены конкретные пользовательские JAR, не все форки.
10. Локальный graphical/protocol QA слушал 127.0.0.1 с offline-auth. Публичная online-mode-аутентификация не проверена. Внешний refreshYggdrasil keys давал ошибки сети; TLS/CA/проверки хешей не отключались.
11. Runtime status по-прежнему пишет DEVELOPMENT/LunaAirDrop=UNVERIFIED: это консервативная статическая строка, фактический объём внешней QA указан отдельно. QA-only WinterProbe не предназначен для основного сервера.

Старые отчёты 0.1.0 сохранены в history/v0.1.0; неудачные промежуточные ticket/worldgen прогоны не удалены. Их числа и ограничения не выданы за новую успешную 0.2.0 проверку. Облачная среда не публиковалась.
