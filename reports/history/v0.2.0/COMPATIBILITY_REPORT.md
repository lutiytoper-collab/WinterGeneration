# Совместимость 0.2.0

**Minecraft строго 1.21.11, Java 21.** Сборка с опубликованным Paper API, без production NMS/CraftBukkit. Климатический pack format94.1. Ничьи пользовательские JAR не патчились и не включены в поставку.

Итоговые JSON имеют префиксы fairy02-final-worldedit-/fairy02-final-fawe-. Старые префиксы отражают предыдущие итерации. Хеши используемого основного JAR сохранены в fairy02-final-invariants.json и screenshots-v2/provenance.json; в текущих QA-папках этот JAR проверен на совпадение.

Luna использует публичный Generator adapter и события. Только выбранные зимние миры; подготовка async с проверкой/записями на main. Физические tickets имеют общий refcount и очищаются по владельцу. В природном QA radius 1, max-y128, snow-only blacklist; это отличается от стандартного radius 2. Другие offset, большие схематики, активный restart, hot reload и динамическое создание дропов не проверены. Неудачный поиск безопасного места может задержать дроп.

Полный Purpur стек и публичная Microsoft-аутентификация не проверены. Внешние Yggdrasil key refresh давали сетевые ошибки в облачных логах; isolated QA успешно завершился. Эта проверка конкретных пользовательских форков не доказывает совместимость со всеми версиями WG/Luna/FAWE.
