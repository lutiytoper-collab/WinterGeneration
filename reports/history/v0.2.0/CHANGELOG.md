# 0.2.0 — выразительный зимний лес

- Широкие заснеженные ели до 24 блоков, отдельные формы берёз/дубов, сильнее снег на исходной листве.
- Связные сугробы, тонкие проходные зоны, извилистые тропы и более плотный подлесок.
- Поляны с аркой/фонарём/скамьёй/камнями; опоры следуют склону без выравнивания земли.
- FAIRYTALE плотнее; размер 11, budget512. Нужен новый конфиг, старые чанки сохраняются.
- ForestPlacementValidator проверяет реальные клетки дерева; FoundationFitter учитывает каждый нижний элемент и локальную почву скамьи.
- Исправлен пропуск выгруженных новых Chunky-чанков. Финальная очередь: ChunkPopulateEvent→getChunkAtAsync(current,false), без permanent decoration tickets и FULL-halo загрузок. Публичные metadata структур, вертикальная защита только для известных глубоких структур.
- Refcount tickets Luna с проверками перекрытия/очистки; декор постоянные tickets не использует.
-146 Java+6Python PASS, повтор обеих реальных Paper интеграций,2seed/320 пар, Purpur smoke,5 настоящих F2 PNG.242PASS/2FAIL/8NOT RUN; ограничения и сохранённые строгие диагностические FAIL описаны отдельно.
- Климатический payload датапака прежний. Архив ZIP пересобран, timestamp/SHA меняется. Домики остаются выключены.

История 0.1.0 сохранена в history/v0.1.0/CHANGELOG.md; прежний JAR/конфиг/скриншоты — dist/previous/0.1.0/.
