Request latency включает очередь/native подготовку/готовый halo, это не CPU одного чанка. Нельзя сравнивать с 0.5 как с контролируемым benchmark.

Первая visual прегенерация 1089 чанков завершилась за 72 с;дополнительные village361/225 заняли 29/61 с при работающем программном графическом клиенте. Логи сохраняют фактические этапы. Эти числа не доказывают производительность боевого сервера.

Три новые native2D noise функции кэшируются;изменение рельефа идёт в штатном noise pipeline. Поздний декор не держит постоянных tickets/не промотирует FULL halo. Только Luna preparations удерживают bounded refcount leases. TickWorkBudget ограничивает фактические callbacks, но 2 ms budget мягкий и один объект может дольше.512 записей/11×11 не относятся к native деревьям/рельефу.

Software llvmpipe F2-клиент работал около 2 FPS, что не равно serverTPS. Полный 50–100 player soak, стабильные 20 TPS, peakRSS и боевой plugin stack не измерены. Прегенерация порциями предпочтительна.
