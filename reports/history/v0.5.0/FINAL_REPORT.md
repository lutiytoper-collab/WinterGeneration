# MidgardWinterWorld 0.5.0 — Anarchy Fantasy

Один JAR с native pack, исправлениями очереди декора и шестью небольшими композициями. Новый декор не содержит драгоценных блоков, аметиста, редких ламп и синего/уплотнённого льда. Обычные survival-материалы добываются; старые чанки автоматически не меняются.

**301 PASS /1 FAIL /0 BLOCKED /11 NOT RUN.** 177 Java +23 Python PASS без skipped. TEST VERIFIED в указанном объёме, не RELEASE CANDIDATE.

Исправлены обход tick-бюджета поздними async callbacks, отключение native pack через enabled:false, втягивание липкого поршня и зависшие pending-маркеры. Новые композиции: две арки на основе внешних CC0-контуров и четыре собственных святилища/руины. Плагин и датапак содержат JSON/NBT; размещает плагин через общий preflight. Большие здания, мосты и сеть дорог не реализованы.

Один побайтно одинаковый финальный JAR проверен на пяти площадках без внешнего datapack ZIP. Paper WG/Luna+WorldEdit 7.3.19 и отдельно FAWE 2.16.2: по 28 fixtures, три реальные клиентские проверки Luna, естественный снег, End cleanup с нулём tickets, Chunky и stop. Все шесть NBT загружены публичным StructureManager. Поршень проверялся синтетическим Bukkit event, не физической redstone-моделью. Purpur 2568: четыре ROI и enabled→disabled restart. Normal enabled→enabled rediscovery остаётся исторической проверкой 0.4.

Отдельный survival-клиент без OP действительно сломал естественный блок руины, поставил свой блок и разрушил его TNT. Генератор не создаёт приватов и не блокирует действия игроков. Это не проверка/изменение правил любых сторонних плагинов на чужом сервере.

Матрица seed 825180311: 64 ROI на вариант, initial/restart; vanilla baseline повторно использован. Совпали 1 572 785 raw states на одинаковых подземных координатах пересечения окон, проверенные руды на всей сохранённой высоте, bbox структур и block entities. Сырой variable-window тест сохраняет FAIL в 131,135: native стволы меняют высоту и набор выбранных координат. Он не переименован в PASS.

[Реальные кадры](screenshots-anarchy05/README.md): арки, святилище и F3. Четыре оригинальных F2 PNG проверены побайтно с native originals, по SHA и CRC всех PNG chunks. Официальный клиент 1.21.11 без шейдеров/resource pack/обработки, постройки для выбранных сцен вручную не строились. Мир возобновлён после прерываний облачной сессии; финальный visual stop/save завершён штатно. Неподходящие ракурсы сохранены отдельно и не входят в галерею.

Полный soak 50–100 игроков, все края крон и биомов, экономика, crash atomicity и специальные Luna сценарии не выполнены. Точное покрытие — TEST_RESULTS.md/test-results.json. Облачная конфигурация не публиковалась и старые draft-изменения не применялись повторно.
