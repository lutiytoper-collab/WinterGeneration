# Отклонённый прототип плоских снежных полей

Пользователь уточнил, что нужны естественные пологие луга с небольшими холмами, структурами и редкими деревьями, а не пустая плоскость. Этот прототип (JAR SHA25675bd3d98bc3700b1f5489f798c03122eecd1a099a667e1cd5d6e06b16c0b390f) не опубликован как релиз. Его проверки и диагностические файлы сохранены отдельно от текущей сборки.

Кадр02 содержит пустое небо из-за высоты камеры и дистанции прорисовки; он не принят как игровой образец. Новые кадры текущей версии снимаются заново. Тег карверов, снежный пол и полное отключение декора удалены из реализации.
