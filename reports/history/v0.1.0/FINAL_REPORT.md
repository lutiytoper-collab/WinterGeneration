# MidgardWinterWorld 0.1.0 — итог

Разработаны Java 21 плагин для Minecraft **строго 1.21.11**, зимний datapack 94.1, конфигурация, core/Paper adapter, отдельный QA probe, повторяемые build/runtime scripts, исходники и доказательные отчёты. Архитектура: ванильная генерация рельефа + климат 23 разрешённых биомов + ограниченный декор новых чанков. Пользовательские LunaAirDrop и WorldGuard JAR не патчились и не включены в дистрибутив.

**Статус: TEST VERIFIED в перечисленных сценариях. RELEASE CANDIDATE не присвоен.** Рабочая сборка использует опубликованный официальный Paper API 1.21.11. Серверы Paper/Purpur действительно запускались. Среда была опубликована пользователем ранее; повторная публикация и повторное применение прежних изменений конфигурации не выполнялись.

## Результаты

**PASS 287, FAIL 1, BLOCKED 0, NOT RUN 8.** Полный проверяемый каталог — test-results.json, сводная таблица — TEST_RESULTS.md. Java unit/contract: **117 PASS, 0 failures/errors/skipped**; Python unit: **6 PASS**. Контрактные тесты выполнены с настоящим предоставленным Luna JAR. 6000 запросов Mojang-reference считаются одной проверкой партии, а не шестью тысячами отдельных тестов.

Один FAIL — диагностическое строгое равенство снимков seed **-892041**: пять seagrass↔water и дополнительное BEE_NEST. Сырые отличия сохранены. Геометрия твёрдых блоков/руд в выбранном нижнем диапазоне, bbox после reload, сохранность исходных block entities и restart-идемпотентность прошли на всех трёх seed. Это не доказательство полного поблочного равенства всех миров.

Реальная матрица: seeds **825180311, 42, -892041**, по 256 ROI-чанков на vanilla/winter мир, **1536 уникальных ROI**, **3072 запроса с restart**. Проверены координаты и климат 37 биомов (23 winter +14 excluded), API bbox 11 типов структур. Координаты и карта — COORDINATES.md, test-coordinates.csv, world-map.svg; карта не является игровым скриншотом.

Исторические матрицы сняты на соответствующих предыдущих сборках, а итоговый JAR — на финальных integration runs. Хеши и совпадение содержимого datapack сохранены в final-provenance.json. После матрицы менялась интеграция/валидация аирдропов. Seed 825180311 снят до пограничного исправления на ROI, где оно не применяется; два остальных — после. Старые миры не выдаются за повторно сгенерированные последним JAR.

## Исправленные ошибки

Нативный freeze_top_layer создавал 76 ICE в desert/warm_ocean у холодного river. Добавлена ограниченная коррекция новых чанков через публичный vanillaBiomeProvider и точный biome zoom; регрессия seed 42 прошла. Zoom проверен по оригинальным Mojang-классам, без NMS в плагине и без отключения подписей.

Добавлены ограниченная очередь готовности соседних структур, полные preflight объектов, PDC, защита изменений игрока/WG/block entities и ограниченная статистика. Неверные конфиги не заменяют работающую runtime-конфигурацию. Неподходящий Java 25 WorldEdit заменён совместимым 7.3.19.

Штатный async/synchronous-worldload поиск Luna заменён через публичный Generator безопасной async-подготовкой. Исправлены registry-biome blacklist, высота над тонким снегом, центр площадки ниже соседей и безусловный prefetch во время/после End. Учитываются владельцы tickets; просроченные будущие точки сбрасываются. Полный журнал — CHANGELOG.md.

## Совместимость

Paper **1.21.11-132** — PASS: matrix/audit/integrations. Purpur **1.21.11-2568** — PASS ограниченного pack/plugin/restart smoke; полный Luna-набор на Purpur NOT RUN. Пользовательский WorldGuard **7.0.16**, WorldEdit **7.3.19**, FAWE **2.16.2**, LunaAirDrop **1.0.3-MidgardFix**, Chunky **1.4.40** — PASS указанных сценариев; см. COMPATIBILITY_REPORT.md.

В обоих финальных профилях прошли **19 контролируемых проверок**, включая реальную отмену Luna старта над водой. На природной точке клиент протокола Minecraft 1.21.11 открыл настоящий 54-слотовый Luna inventory с предметами. После End снег сохранён, блок AIR, tickets/active/preparations равны нулю. WorldEdit: (-472,67,-411), snow layers=1; FAWE: (-124,68,-908), layers=2.

Природный QA использовал single-chest **3×3**, max-y=128, y-offset=1 и явно документированный snow-only blacklist. Поставляемый config имеет более строгую площадку **5×5**. Эти результаты нельзя переносить на произвольные схематики. Клиент — loopback/offline-auth, графики нет; публичная Microsoft-аутентификация не проверялась. Внешний Yggdrasil public-key запрос в облаке возвращал Connection refused.

## Производительность

Paper, Java 21, Xmx2G, 4 CPU quota, 32 GiB cgroup, пустые миры, одинаковый tick freeze. Средние задержки chunk request→completion vanilla/winter: **78.49/81.81ms**, **77.66/80.18ms**, **65.70/86.78ms** для трёх seed соответственно. Winter P95: **808.72/775.14/787.15ms**. Задержка включает очередь и подготовленные соседями чанки, а не только CPU новой генерации. Полные mean/median/P95/max и heap start/end — PERFORMANCE_REPORT.md и сырые JSON. Статистической гарантии overhead/TPS и нагрузки 100 игроков эти прогоны не дают.

## Оставшиеся работы

NOT RUN: графический художественный осмотр; длительная нагрузка 50–100 игроков; полный Purpur plugin stack; полный перебор высотных границ биомов; аварийная атомарность; восстановление активного Luna; hot reload/dynamic drops; большие схематики/custom Y offsets. Законченная система тропинок и дополнительные ветви существующих деревьев не реализованы, домики выключены до осмотра. Консервативная защита уменьшает плотность декора. Полный список — KNOWN_ISSUES.md.

При высотной неоднозначности исходного климата пограничная коррекция пропускает блок: глобальное отсутствие утечки снега за allowlist пока не доказано. Полость проверяется только в support-depth. Сбой процесса может оставить частичный объект без rollback. Runtime-надпись DEVELOPMENT/UNVERIFIED намеренно консервативна; фактическую QA следует читать в этом отчёте.
