# Генерация: подтверждения и границы

Minecraft строго 1.21.11. Оригинальные определения всех 23 biome JSON совпадают с ресурсами официального Mojang server JAR, проверенного по SHA-1 из version manifest. Формат datapack 94.1 подтверждён version.json. Датапак успешно загружался Paper 132 и Purpur 2568. Только temperature=-0.5 и has_precipitation=true отличаются от оригиналов. Features, carvers, spawners, effects и registry references сохранены. Нет noise_settings, dimension, ore/structure overrides.

Строгий plugin allowlist допускает лишь подмножество 23 штатных зимних биомов в NORMAL и явно названных мирах. Пустой список запрещает декор; ошибочные ID/параметры отвергаются. Nether/End и горячие биомы не включены. Плагин не заменяет ванильный ChunkGenerator.

Проверены реальные 37 biome locations (23 разрешённых +14 исключённых) и температуры. Найдены и подтверждены API bbox 11 типов структур: village_plains, village_snowy, pillager_outpost, mansion, ruined_portal, stronghold, mineshaft, ancient_city, trial_chambers, shipwreck, ocean_ruin_cold. Seed 825180311, координаты — COORDINATES.md/test-coordinates.csv; сырые записи — runtime-audit.json. Обнаружение структуры не означает проверку каждого её блока/сундука.

Три пары vanilla/winter на seed 825180311, 42 и -892041: по 256 ROI-чанков на мир, всего 1536 уникальных ROI и 3072 запроса с restart. Измерения и консоли скопированы в reports/runtime. Нижняя выборка -64..min(31,surface-8) сравнивается хешем и при различиях читается из настоящих Anvil/NBT. Твёрдая геометрия/руды, bbox после reload, сохранение исходных block entities и restart-идемпотентность прошли во всех трёх парах.

**Строгое равенство снимков не прошло на seed -892041:** пять seagrass↔water и дополнительное естественное BEE_NEST (2087,63,2054). Сырой список сохранён в invariant-validation.json/exact-underground-diff.json/server-matrix-boundary-final.json. Нормализация водных растений относится только к геометрическому сравнению; она не делает исходные блоки поблочно равными. Существующие block entities не потеряны. Полное поблочное равенство всех высот/миров не заявляется.

В первой версии native freeze_top_layer создал 76 ICE за allowlist на границах river/desert/warm_ocean. Публичный vanillaBiomeProvider и точный biome zoom позволили восстановить исходно тёплую поверхность только в новых чанках. Итоговая регрессия seed 42: ноль зимних блоков, добавленных в проверенных исключённых биомах, поверхность совпадает с vanilla. Проверка zoom: 6000 сэмплов и шесть seed hash против оригинальных Mojang-классов (отдельный dev oracle; не распространяется и не используется в плагине). Высотные неоднозначные случаи остаются ограничением; см. KNOWN_ISSUES.md.

Матрица seed 825180311 снята до пограничного исправления: её ROI состоит из разрешённых биомов, где исправление является no-op. Seed 42 и -892041 сняты после него. Последующие изменения касались LunaBridge, который в матрице отсутствует. Пересборка не выдаётся за повторную генерацию старых миров.

Объекты получают полный preflight всех ячеек и опоры, размер/бюджет проверяются до записи. Новые PDC 1=pending,2=processed,3=skipped не снимаются для повторного декора. Чанки рядом с игроком, регионами, bbox структур и block entities консервативно пропускаются; декор соседей не загружает. В queue максимум 512 чанков/100 тиков, до четырёх проверок за тик и soft budget 2ms; один объект/проверка может занять больше, hard real-time guarantee нет.

Карта world-map.svg построена из реальных замеров, но не является игровым скриншотом. Художественная приёмка, полноценные тропинки, проверка больших домиков/схематик, полные высотные границы и длительная SMP-нагрузка остаются вне подтверждённого объёма.
