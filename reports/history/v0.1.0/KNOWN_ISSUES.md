# Ограничения итоговой проверки

Статус TEST VERIFIED относится к измеренным сценариям, а не к готовности сервера с полным набором плагинов и 100 игроками.

1. Нет графических скриншотов и художественного приёмочного осмотра. Mineflayer проверяет протокол и инвентарь, а SVG-карта показывает данные. Координаты для ручного осмотра предоставлены. Домики выключены; отдельная законченная система тропинок и дополнительные ветви на существующих деревьях не реализованы.
2. Не выполнен длительный нагрузочный прогон 50–100 игроков. Матрица — последовательные запросы пустого сервера с замороженными тиками. Heap start/end не являются максимальным RSS. Нет TPS-гарантии по этим данным.
3. Строгое поблочное равенство всего ванильного мира не установлено: seed -892041 имеет пять различий seagrass/water и дополнительное естественное BEE_NEST. Они сохранены в сырых отчётах. В проверенном объёме геометрия твёрдых блоков/руд, структуры после reload и исходные block entities сохранены. Нижняя выборка ограничена -64..min(31, surface-8), а не всеми блоками всех чанков.
4. Пограничная коррекция устранила 76 незаконных ICE в warm_ocean/desert в регрессии seed 42. При неоднозначной исходной температуре на большой высоте коррекция консервативно пропускает блок; полный перебор высотных границ всех биомов не выполнен. Строгое глобальное отсутствие утечки нативного снега за allowlist не доказано. Датапак следует использовать вместе с плагином.
5. Защита целого чанка при block entities/структурах, ожидание доступных соседей и запрет около игроков могут уменьшать плотность декора. Итог размещения зависит от доступности соседей. Структуры без API metadata/block entities не гарантированно распознаются. Авария между записями может оставить частичный объект; автоматического rollback нет.
6. Природный Luna QA использовал radius=1 (3×3), max-y=128 и SNOW вне native blacklist (snow-only QA: сухие материалы опоры дополнительно запрещены). По умолчанию плагин требует radius=2 (5×5). Крупные схематики, Y offsets кроме 1, горячий reload/создание новых дропов после регистрации, восстановление активных дропов через restart и чужие поздние изменения location не проверены. Поиск ограничен 32 районами за 5 минут на дроп, до 16 позиций в каждом, и паузой 30 секунд после End; отсутствие безопасной площадки может задержать появление.
7. Полость проверяется только до support-depth. Глобальный WG-регион блокирует декор всего мира; ошибки WG API закрывают размещение. Результат проверен с конкретными пользовательскими JAR, не с любым форком.
8. В облачных логах есть Connection refused при обновлении внешних Yggdrasil public keys. Создание миров и интеграции работают; публичная online-mode-аутентификация игроков не проверена. TLS/подписи/хеши не отключались. Offline-mode QA слушал только 127.0.0.1.
9. Purpur проверен загрузкой датапака, новым небольшим ROI и restart; весь набор Luna/WG/FAWE интеграций выполнен на Paper. Не следует переносить этот объём на Purpur автоматически.
10. Runtime-команды пока сохраняют консервативную строку DEVELOPMENT/LunaAirDrop=UNVERIFIED; фактический объём внешней проверки зафиксирован в отчётах. Ретрогенерации и автоматической уборки существующего декора нет. Изменение plugin allowlist не изменяет климат 23 биомов установленного датапака.

Сетевые ограничения старого этапа сняты: официальный сервер/API, WorldEdit/FAWE/Chunky получены и проверены, Paper и Purpur запускались. Исторические ошибки в логах не удалены; их не следует смешивать с итоговым каталогом проверок.
