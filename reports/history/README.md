# Исторические этапы

Файлы initial-* сохраняют старый этап BUILD VERIFIED, когда сетевой policy запрещал официальный сервер/API. Позднее доступ появился, опубликованный API и официальные серверы получены и runtime-испытания выполнены. Актуальная сводка находится на уровень выше в FINAL_REPORT.md/TEST_RESULTS.md/test-results.json.

В reports/logs и отдельных JSON оставлены ранние ошибки: HTTP 403, неподходящий Java 25 WorldEdit 7.4.6, неверное locate имя mansion, незамороженные жидкости vanilla, ранние ICE за allowlist, отключённая клиентская физика, старый синхронный Luna selector, истёкший поиск/End с повторным prefetch, приподнятый центр площадки. Их логи не исправлялись задним числом.

Часть промежуточных прогонов (release-async-*, snow-release-*) остановлена командой stop перед заменой проверяемого JAR следующей исправленной сборкой. Runner корректно вернул ненулевой статус из-за незавершённого сценария; server exit 0 в этих логах означает только штатную остановку. Они не входят в итоговые PASS.

Некоторые старые natural-luna.json описывают только успешный Start без End-полей: последующая cleanup-проверка могла завершиться FAIL в console log. Такие частичные файлы не подтверждают полную совместимость. Итоговые завершённые прогоны перечисляются в final-integration-profiles.json и проверяются scripts/report.py по реальным JSON и финальным консольным маркерам.

Строгое сравнение seed -892041 осталось отдельным FAIL в итоговом каталоге. Его не следует относить к уже устранённым ошибкам. Сохранены все пять различий seagrass/water и дополнительное BEE_NEST.
