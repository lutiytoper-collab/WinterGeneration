# Third-party geometry

Two moon gate outlines use circle geometry by Greaby from [minecraft-circles-schematics](https://github.com/Greaby/minecraft-circles-schematics), commit `1263463cffb59b08275e9ee9408848285c4cddff`, under **CC0-1.0**.

Only `circle-7x7.litematic` and `circle-9x9.litematic` are used. Original files, LICENSE, pinned URLs and SHA-256 hashes are preserved in [vendor/schematics/greaby-circles](vendor/schematics/greaby-circles). These are flat stone circle outlines, not finished fantasy buildings. Midgard rotates the outlines upright, changes materials and adds a winter base and crest.

The plugin embeds `licenses/greaby-circles-CC0.txt`. The four shrine/ruin compositions are original project assets; the third-party CC0 license does not describe those compositions. No license change for the whole repository is implied.

WorldEdit, Minecraft server binaries and user-provided integration plugins are not distributed. Vanilla data provenance is recorded separately in vendor/ and generation reports.
